Step 1 — Which layer?
  Is the error in a component/app file?     → Leptos layer
  Is it about cfg/features/target_arch?     → SSR/WASM boundary
  Is it in services/blockchain/**?          → Alloy layer

Step 2 — What kind?
  E0433 unresolved crate                    → wrong layer (importing SSR thing in WASM or vice versa)
  E0282 type annotations needed             → Rust can't infer across async boundary → annotate explicitly
  E0525 FnOnce vs FnMut                     → closure called inside reactive closure → change Children to ChildrenFn
  E0761 module found at both paths          → old flat file still exists alongside new folder → delete the flat file

Step 3 — Fix with understanding, not just copy-paste
